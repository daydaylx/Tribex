# TribeX – Milestone Roadmap

## M0: Scaffold + Audio Smoke Test
Build + Oboe integration + 440Hz test tone + Start/Stop UI. No sequencer, no samples, no DB.

## M1: Sequencer Core
Step grid (16 steps), tempo, play/pause, step indicator. Still test tone only (no samples).

## M2: Drum Sampler
Sample loading, 8 drum parts, velocity, basic ADSR. Pattern triggers samples.

## M3: FX Chain
Delay, Reverb (sends), Valve saturation, Limiter. Master bus processing.

## M4: Parameter Locks + Motion
Per-step parameter overrides. Motion recording/playback.

## M5: Synth Part + Patterns
Wavetable synth, chord mode. Pattern chaining, pattern management.

## M6: Sample Import + Export
WAV import, internal resampling, chain export (offline render).

---

**Current focus: M0 only.** Do not implement features from M1+ until M0 is stable and accepted.
